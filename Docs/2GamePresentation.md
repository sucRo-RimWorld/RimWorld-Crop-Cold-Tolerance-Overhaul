# RimWorld Mod データベース（2game）掲載方針 — CCTO

対象ページ: https://rimworld.2game.info/detail.php?id=3812412548

2gameでは検索一覧からMODの用途を判断しやすいことを優先し、Steam Workshopよりさらに簡潔な日本語説明を使う。

見出し記号は、2gameで一般的に使われている `▼` に統一する。`◆` は使わない。

本文は常体で書く。1文に複数の説明を詰め込まず、1文1情報を基本に短く区切る。箇条書きも可能な限り短い句または1文でまとめる。

形式は2gameのAI自動生成要約を参考にする。基本構成は「短い要約 → `▼ 見出し` → 短い箇条書き」とする。見出しの `▼` の後には半角スペースを入れる。Workshopの節構成をそのまま持ち込まない。現在の正本では `主な機能`、`バランス方針`、`対応範囲`、`対応・互換性`、`セーブ互換性`、`今後の予定` の順で整理する。2game内の関連MODは同サイトの詳細ページURLを直接記載する。

## 説明文

貼り付け用の正本:

`Docs/2GameDescription-ja.txt`

掲載内容は以下を優先する。

- 現実の耐寒性を参考にした植物ごとのバランス調整であること
- 最低生育温度・固定枯死温度・低温休眠
- 耐寒性以外の作物性能は変更しないこと
- Core 49 / Medieval Overhaul 29 の現在対応範囲
- 野生植物も対象であること
- 他Mod向けXMLフレームワークとして利用できること
- Harmony必須、MO等は任意対応
- 既存セーブへの追加・削除の扱い
- VPEは将来対応で、まず基本セット20種を予定していること

AMJ/AMJCで追加予定の作物はCCTOの対応範囲・予定として記載しない。

## 推奨タグ

優先して付ける:

- `バランス調整`
- `植物`
- `農業`
- `栽培`
- `パッチ`
- `Harmony`
- `日本語内蔵`
- `和製MOD`

### 現時点では付けないタグ

- `作物` / `野菜` — 新しい作物を追加するMODと誤認されやすい
- `高難易度化` — 全体として寒さは厳しくなるが、一律の難易度上昇を目的としたMODではない
- `インターフェイス` / `UI` — Info Card表示はあるが主機能ではない
- `MOD間調整` — MO等との互換はあるが、互換パッチ集が主目的ではない
- `VPE` — 現在は未対応。実際にVPE対応を公開してから追加を検討する
- `中世` — CCTO自体は中世環境専用ではない

タグは検索導線として機能するため、実装済みの現在機能を表すものだけを付ける。
