# CCTO V3：作物の使い分けと農業上の役割

作成日：2026年10月25日

## この資料の位置づけ

確定したV3設計値から季節・気候・土地・用途ごとの使い分けを考察する**参考資料**。CCTOの採否基準は[現実性を最優先する設計方針](Design.md#governing-objective-and-verification-boundaries--clarified-2026-10-26)による。農業経済の順位や全作物に独自の経済的強みを保証することは**目的でも公開条件でもない**。

mainの本番XML/DLLはV3未反映。ただしDraft V3はオリジナルRimWorld 1.6の温度固定通常Tick 19/19と実RWS二工程保存・復元を通過。自然の全季節・1.7・配布物の検証とは区別する（[証跡](Coordination.md#v3-original-16-native-technical-acceptance--2026-10-25)）。

対象はCCTO本体のバニラ・Medieval Overhaul（以下MO）の作物。CCTO for VPEは本体完了後に扱い、この資料の対象に含めない。ここでの考察によって確定値を変更しない。

数値の正本は[確定値一覧](ColdDamageHpV3Candidates.csv)。採用理由・数値監査は[監査記録](Research/ColdDamageV3BatchReview.md)、仕様は[設計書](Design.md#current-v3-numerical-specification--finalized-2026-10-25)を参照。

## 選択の基本になる五つの軸

1. **収穫までの時間**：短い栽培期間に間に合うか。食料不足の解消を急ぐか、一作でまとめて備蓄するか。
2. **成長できる気温**：寒さで生き残っても、成長が止まれば新たな収穫にはつながらない。
3. **寒害による損失**：一晩の霜だけでなく、複数の夜を通してHPと収穫がどれだけ失われるか。
4. **土地・設備・労働力**：肥沃な土地を使う価値、痩せた土地での生産性、播種・収穫回数、保護栽培の費用。
5. **収穫物の用途**：主食、料理・加工の材料、家畜飼料、医薬品、衣料・交易品を区別する（CCTOの調整対象外の参考情報）。

**耐寒性が高いことと、冬にも生産できることは別。** 最低成長温度、寒害開始温度、休眠はそれぞれ異なる。休眠は株を残す方法であり、冬季の増産を保証しない。現在確認した実装には、休眠だけを理由とする収穫禁止もない。

HP型の寒害は暖かくなってもCCTOによって自動回復しない。春の被害が夏の収穫へ持ち越されることもあるため、「生き残ったから損失なし」とは扱わない。

## 主な作物の役割

最低成長温度は現行CCTOの互換XMLに記載された値、寒害開始温度は確定したV3値。両者を組み合わせた**設計上の予測**であり、他Mod適用後のロード済みDefを確認したものではない。下限ちょうどで十分な速度で育つことも意味しない。

| 作物 | 最低成長温度 | 寒害開始温度 | 想定する使いどころ | 選ぶ際の注意 |
|---|---:|---:|---|---|
| 米 | 10℃ | ＋2℃ | 入植直後、食料不足からの復旧、夏の短期作付け | 生育は速いが、寒い時期の追い播きは危険。短期生育と耐寒性を混同しない |
| トウモロコシ | 8℃ | 0℃ | 暖かい季節の主力・まとめて備蓄する畑 | 成熟まで長いため、秋に未成熟の畑を残すと投資を失いやすい |
| ジャガイモ | 5℃ | −2℃ | 痩せた土地、春秋も含めた比較的安定した食料生産 | 肥沃度への依存が低い。寒冷地でも成熟までの期間は必要 |
| イチゴ | 5℃ | −2℃ | 生食できる補助食料、食料源の分散 | 主食の生産量だけでなく調理を介さない用途を評価。花だけの弱霜被害は現行HPモデルで再現しない |
| MOタマネギ | 5℃ | −5℃ | 痩せた土地、冷涼期の短期生産 | 低温成長と寒害を区別する。肥沃度や収量はCCTOの調整対象外 |
| MOニンジン | 0℃ | −7℃ | 春の先行作付け、秋の最後の一作、短い栽培期間 | 低温に強く生育も短い。ただし収量・料理用途・技能条件まで含めて比較する |
| MO小麦 | 0℃ | −7℃ | 冷涼な地域の主穀・加工原料 | 耐寒性は高いが生育が長い。収穫後の加工とその労働も必要に応じて考慮 |
| MOキャベツ | 0℃ | −3.5℃ | 冷涼期の野菜生産 | 最低生育温度0℃は適温を意味しない。MO 1.6の最適温度XML誤記に注意 |
| MOレンズ豆 | 5℃ | −5℃ | 短期に収穫できる冷涼期の豆類 | 原Defの栽培技能条件が高いため、入植直後から誰でも使える代替米ではない |
| MOトマト | 10℃ | 0℃ | 夏の短期回転、料理用の野菜 | 霜に弱い。秋の畑に長く残さず、収穫時期を見込んで播く |
| MOカボチャ | 10℃ | 0℃ | 暖期に時間を確保して収穫する野菜 | トマトより生育が長い。寒害係数は同じでも、露地での作付けリスクは同じではない |
| 牧草 | 0℃ | −8℃ | 家畜用の冬季備蓄 | 人間用の食料畑とは別枠。耐寒性があっても冬前の必要量を確保する |

寒害開始温度が低い順の単純な順位では決められない。例えば、米は寒さに弱くても収穫までが短く、小麦は寒さに強くても長い生育期間が必要になる。同じ土地でも残りの暖期によって有利な作物が変わる。

## 季節ごとの組み合わせ

### 春：食料のつなぎと先行作付け

昼に暖かくなっても夜の霜が残るなら、ニンジンなど成長下限が低い作物を先に播く選択が生まれる。夜温が安定した後に米を播けば、速い収穫で備蓄を立て直せる。

一方、「早く播けば必ず得」とは限らない。成長がほとんど進まない低温期に寒害だけ受けると、夏まで残るHP損失を抱える。播種を待つ方がよい局面もある。

### 夏：主食を確保して用途を広げる

十分な暖期があるなら、トウモロコシなどを主力にして備蓄を確保し、一部を夏野菜・綿・薬物・交易用作物へ振り分ける。米の短期回転を続けるか、収穫回数を抑える長期作物へ切り替えるかは、農作業に割ける人数にもよる。

全畑を同じ作物・同じ日に播くより、用途と収穫時期を分けると、特定の時期の寒波による損失を分散できる。ただし区画を分けるだけで同じ温度履歴の作物の耐性が変わるわけではない。

### 秋：最後の一作と収穫優先

次に播く作物は耐寒性だけでなく、成熟までに必要な暖かい時間で選ぶ。短期・低温対応の作物は最後の一作の候補になるが、長期作物は生存しても収穫に間に合わない可能性がある。

霜に弱いトマト・カボチャは、収穫可能なら畑に置き続けるリスクが高い。現在のw=0設計では、同じHP・同じ温度履歴の個体が同じ結果になり得る。「畑の一部は必ず残る」という救済を前提にしない。

### 冬：備蓄・保護栽培・越冬を分ける

露地の生産が止まる地域では、食料と牧草の備蓄が基本になる。保護栽培できるなら、必要な食料量と医薬・工芸作物の価値を比較して面積を配分する。水耕栽培の可否は作物ごとに異なり、全作物に使える設備とは扱わない。

Healrootや休眠する多年性の植物は、株を残す価値を持つ。ただしそのことから冬季に成長・成熟・増産できるとは推測しない。

## 気候・土地・労働力による選択

| 条件 | 生まれそうな選択 | 比較で見落としやすいこと |
|---|---|---|
| 寒冷地・短い夏 | 短期作物を軸にし、低温対応作物で前後の作付けを補う | 耐寒性の高い長期作物が、短期作物より有利とは限らない |
| 温帯・春秋に霜 | 夏の主力と春秋向け作物を分ける | 畑の切替日を固定せず、残りの成長期間と夜温を見る |
| 温暖地・長い栽培期間 | 収量、労働、加工・料理用途の比重が増す | CCTOの耐寒差がほとんど出ない土地では、寒害値だけで役割を説明できない |
| 痩せた土地 | ジャガイモ・タマネギなど肥沃度への依存が低い作物を検討 | 低感受性は痩せた土地での利点であり、肥沃な土地で常に最高効率という意味ではない |
| 肥沃な土地が限られる | 肥沃度の恩恵が大きい作物を優先する余地 | 収穫物の栄養価・成熟時間・必要量も合わせて考える |
| 農業労働力が少ない | 長期作物や備蓄型の生産を検討 | 一作あたりの播種・収穫作業量と、寒波で失う投資を比較する |
| 食料不足が目前 | 早く収穫できる作物を優先 | 安定時の長期効率より最初の収穫日が重要になる |

MOの収穫個数だけを横並びにして「最強作物」を決めない。食材ごとの栄養価、保存・加工・レシピ、栽培技能、労働時間によって評価が変わる。この資料では、それらを統合した食料効率の順位は算定していない。

## 食料以外の作物

| 用途 | 主な作物 | CCTOで生まれそうな判断 |
|---|---|---|
| 医療 | Healroot | 越冬して株を残す価値が高い。食料畑と競合する面積、必要な医薬品備蓄を別に決める |
| 衣料・素材 | 綿、MO亜麻 | 暖期の綿と、比較的低温に強い亜麻を用途・製造工程と合わせて選ぶ。同じ素材の完全代替とは断定しない |
| 高価な工芸素材 | デビルストランド | 生育が非常に長く、秋の寒害で失う投資が大きい。長い暖期や保護栽培の価値が高まる |
| 嗜好品・薬物 | スモークリーフ、サイコイド、ホップなど | 必要量・加工設備・土地の競合を考える。耐寒性だけを理由に栽培量を増やすわけではない |
| 果樹・多年性作物 | リンゴ、レモン、ブドウなど | 初期投資と複数回の収穫を考える。休眠・樹体生存・果実霜害は別で、現行の単一HPでは完全に分離できない |
| 家畜飼料 | 牧草 | 人間用食料の生産を圧迫しない面積配分と、冬季の給餌量を考える |

## CCTOで確認する温度反応

CCTO自身の温度・HP・休眠・自生地での植物生存が検証対象。収量・レシピ・生育日数・作業量の優劣を揃える試験ではない。既存の実機証跡を再利用し、具体的な不整合のみ対象を絞って確認する。

| 観点 | 確認内容 | 異常の例 |
|---|---|---|
| 生育下限と最適域 | 生育停止、低温減速が現実の生理とロード済みDefに合う | キャベツが3℃と生育適温で同速度 |
| 累積寒害 | 普通の霜、強い寒波、反復曝露が説明可能なHP損傷を生む | 係数の逆算だけで妥当と判定、普通の霜で大量枯死 |
| 自然植生と休眠 | 各植物の自生地における通常の冬の生存、休眠との違い | 標準的な冬に森林や牧草が恒常的に消える |
| 技術的互換性 | Vanilla＋CCTO、任意のMO＋CCTOでのDef・UI・セーブ復元 | 誤った温度表示、HP記録消失、例外 |

キャベツの最適域15～20℃は現実の資料に基づく**候補**であり、現時点で採用された値ではない。MO 1.6の重複タグを修正するだけの最適域0～25℃も、現実性の承認ではない。キャベツとニンジン・タマネギの収量、加工、Agriculture併用時の生産性は参考情報にとどめ、CCTOの係数の根拠にしない。
