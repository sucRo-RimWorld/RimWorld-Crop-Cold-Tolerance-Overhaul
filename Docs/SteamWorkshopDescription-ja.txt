[h1]作物耐寒性オーバーホール（CCTO）[/h1]

CCTOは、植物の[b]最低生育温度[/b]と[b]低温による枯死[/b]を分けて扱い、植物ごとに明確な耐寒性を設定するModです。
一部の植物には[b]低温休眠[/b]を設定しています。休眠する植物は寒くなると成長を止めて葉を落としますが、枯死せず、気温が上がると回復します。

Vanillaでは、低温による落葉・枯死の温度は最低生育温度をもとに個体ごとに算出されます。CCTOでは、対応する植物ごとに固定の枯死温度、または休眠温度を設定します。

対象は農作物だけではありません。果樹、植林用樹木、観賞植物、菌類、草、低木、野生植物など、[b]対応するCore / Medieval Overhaul内の生きた植物すべて[/b]が対象です。プレイヤーが栽培できるかどうかは問いません。
切り株など、すでに枯死した植物の残骸は対象外です。

[h2]主な変更[/h2]
[list]
[*]植物ごとに最低生育温度を設定
[*]休眠しない植物には固定の枯死温度を設定
[*]一部の多年草・越冬植物・落葉樹に低温休眠を追加
[*]情報カードに「枯死温度」または「休眠温度」を表示
[*]Nice Plants Menuに対応（任意）
[*]Dubs Mint Menusでは標準の情報カード経由で表示
[/list]

CCTOが変更するのは[b]耐寒性に関する項目だけ[/b]です。
収穫量、成長日数、肥沃度、保存期間、加工、研究などは変更しません。

[h2]バランス方針[/h2]

現在の設定は、全体としてVanilla / Medieval Overhaulより[b]寒さの影響がはっきり出る調整[/b]になっています。
多くの植物はVanillaより高い温度で成長を停止し、低温に弱い植物には種類ごとの明確な枯死温度があります。

そのため、植物の選択、播種時期、植林計画、暖房、温室、寒波への備えがより重要になります。

一方で、すべての植物を一律に弱くしているわけではありません。
寒冷地の野生植物や耐寒性の高い樹木は、その生息環境で通常の冬を越せるように調整しています。また、一部の多年草や落葉樹は休眠することで冬を生き残ります。

[h2]設定値の考え方[/h2]

各植物の数値は、実際の植物の耐寒性、霜害、低温障害、枯死温度などの情報を参考にしています。

実際の耐寒性は品種、生育段階、低温への順化、寒さにさらされる時間などによって変わるため、実測値をそのまま絶対値として採用しているわけではありません。
実際のデータを基準にしつつ、植物ごとの差がゲーム上で分かりやすくなるよう丸め・調整しています。

[h2]対応範囲[/h2]
[list]
[*]Vanilla RimWorld 1.6：Coreの生体PlantDef 49種
[*]Medieval Overhaul 1.6：独自PlantDef 29種（野生専用植物を含む・任意）
[/list]

野生植物については、本来の生息バイオームで通常の冬を越せることを重視して調整しています。
切り株などの死んだ植物残骸は対象外です。

[h2]変更例[/h2]

[b]米[/b]
最低生育温度：0°C → 10°C
低温：個体ごとに -18～-10°C前後で枯死 → [b]-1°Cで固定枯死[/b]

[b]ジャガイモ[/b]
最低生育温度：0°C → 5°C
低温：個体ごとに -18～-10°C前後で枯死 → [b]-2°Cで固定枯死[/b]

[b]ホップ[/b]
最低生育温度：0°C → 5°C
低温：低温で枯死 → [b]5°C未満で休眠[/b]

[b]Vanilla 竹[/b]
最低生育温度：0°C → 10°C
低温：Vanillaの汎用的な樹木の低温挙動 → [b]-18°Cで固定枯死[/b]
※竹は日本で一般的なモウソウチク・マダケ系を基準にしています。

[b]MO キャベツ[/b]
最低生育温度：-18°C → 0°C
低温：個体ごとに -36～-28°C前後で枯死 → [b]-6°Cで固定枯死[/b]

[b]MO リンゴ[/b]
最低生育温度：0°C → 5°C
低温：落葉して生存 → [b]5°C未満で休眠[/b]

[h2]他Mod向けフレームワーク[/h2]

CCTOは耐寒性リバランスModであると同時に、他Modの植物にもXMLから固定枯死温度や低温休眠を設定できる軽量フレームワークとして利用できます。

開発予定の[b]Ancient & Medieval Japan（AMJ）[/b]も、この仕組みを利用します。

[h2]Betaについて[/h2]

現在のバランスでは、枯死温度を植物種ごとの固定値として設定しています。
季節計画の分かりやすさ、畑全体が同時に枯れる挙動、個体差が必要かどうか、枯死温度・休眠温度の表示についてフィードバックを歓迎します。

[h2]セーブ互換性[/h2]
[list]
[*]既存のセーブに追加または削除しても安全です。
[/list]

読み込み後は既存の植物にも新しい温度設定が適用されます。すでに枯死した植物は、CCTOを削除しても復元されません。CCTOを必須とするModを利用している場合は、その依存関係を維持してください。
