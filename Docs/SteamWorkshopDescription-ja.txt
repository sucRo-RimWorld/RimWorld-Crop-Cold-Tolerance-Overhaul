[h1]作物耐寒性オーバーホール（CCTO）[/h1]

CCTOは、対応対象となるすべての生きた植物Defの[b]最低生育温度[/b]と[b]低温による枯死挙動[/b]を分離し、一部の植物には枯死しない[b]低温休眠[/b]を追加します。
休眠する植物は寒さで成長を停止して葉を失いますが、そのまま枯死せず、気温が上がると回復します。

Vanillaでは、低温時の落葉・枯死温度は最低生育温度から個体ごとに算出されます。CCTOでは、対応する植物Defごとに明示的な枯死温度、または休眠挙動を設定します。農作物だけでなく、果樹・植林用樹木・観賞植物・菌類・草・低木・野生専用植物も対象です。切り株などの死んだ植物残骸は対象外です。

[h2]主な変更[/h2]
[list]
[*]植物ごとの最低生育温度を設定
[*]通常植物に固定の枯死温度を設定
[*]一部の多年草・越冬植物・落葉樹に低温休眠を追加
[*]情報カードに「枯死温度」または「休眠温度」を表示
[*]Nice Plants Menuにソフト互換対応
[*]Dubs Mint Menusでは通常の情報カード経由で表示
[/list]

CCTOが変更するのは[b]耐寒性に関する項目だけ[/b]です。
収穫量、成長日数、肥沃度、保存期間、加工、研究などは変更しません。

[h2]バランス方針[/h2]

現在の設定は、全体としてVanilla / Medieval Overhaulより[b]低温管理の影響が大きくなる方向[/b]です。
多くの植物はより高い温度で成長を停止し、通常植物の多くはVanillaより明確な低温限界を持ちます。農業だけでなく植林でも、樹種と気候の組み合わせが重要になります。

そのため、植物の選択、播種時期、植林計画、暖房、温室、寒波への備えがより重要になります。

ただし、すべての植物を一律に弱体化するものではありません。
一部の多年草・越冬作物は休眠によって冬を生き残れるようになります。

[h2]設定値の指針[/h2]

各植物の数値は、実際の植物の耐寒性、霜害、低温障害、枯死温度などの情報を参考にしています。

実際の耐寒性は品種、生育段階、低温への順化、寒さにさらされた時間などで変化するため、特定の実測値をそのまま絶対値として使用しているわけではありません。
実データを基準にしつつ、植物ごとの差がゲーム上で分かりやすくなるよう丸め・調整しています。

[h2]対応[/h2]
[list]
[*]Vanilla RimWorld 1.6：Coreの生きたPlantDef 49種
[*]Medieval Overhaul 1.6：独自PlantDef 29種（野生専用植物を含む・任意）
[/list]

野生植物は、本来の生息バイオームで通常の冬を越せることを重視して調整します。切り株などの死んだ植物残骸は対象外です。

[h2]変更例[/h2]

[b]米[/b]
最低生育温度：0°C → 10°C
低温：個体ごとに -18～-10°C前後で枯死 → [b]-1°Cで固定枯死[/b]

[b]ジャガイモ[/b]
最低生育温度：0°C → 5°C
低温：-18～-10°C前後で枯死 → [b]-2°Cで固定枯死[/b]

[b]ホップ[/b]
最低生育温度：0°C → 5°C
低温：枯死 → [b]5°C未満で休眠[/b]

[b]Vanilla 竹[/b]
最低生育温度：0°C → 10°C
低温：汎用的な樹木の低温挙動 → [b]-18°Cで固定枯死[/b]
※竹は日本で一般的なモウソウチク・マダケ系を基準にしています。

[b]MO キャベツ[/b]
最低生育温度：-18°C → 0°C
低温：-36～-28°C前後で枯死 → [b]-6°Cで固定枯死[/b]

[b]MO リンゴ[/b]
最低生育温度：0°C → 5°C
低温：落葉して生存 → [b]5°C未満で休眠[/b]

[h2]他Mod向けフレームワーク[/h2]

CCTOは耐寒性リバランスModであると同時に、他Modの植物へXMLから固定枯死温度や低温休眠を設定できる軽量フレームワークとしても利用できます。

開発予定の[b]Ancient & Medieval Japan（AMJ）[/b]も、この仕組みを利用します。

[h2]Betaについて[/h2]

現在のバランスモデルでは、枯死温度は植物種ごとに1つの固定値を使用しています。
季節計画の分かりやすさ、畑全体が同時に枯れる挙動、個体差が必要かどうか、表示の分かりやすさについてフィードバックを歓迎します。
