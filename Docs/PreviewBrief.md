# CCTO 0.1 Beta — Preview Image Brief

Target file:

`About/Preview.png`

## Technical requirements

- Canvas: **640 × 360 px**
- Aspect ratio: **16:9**
- Format: PNG
- Target file size: comfortably below **1 MB**
- Must remain readable both in the RimWorld in-game mod list and on Steam Workshop.

## Visual goal

Communicate the mod's purpose immediately without requiring the Workshop description.

Primary message:

**Crop Cold Tolerance Overhaul**

Secondary message:

**Growth temperature ≠ Cold death**

Optional small line:

**Fixed death temperatures • Cold dormancy • Vanilla + Medieval Overhaul**

## Composition

Preferred layout:

- left/center: simple crop-field or plant silhouettes transitioning from healthy to frost-covered;
- a clear thermometer/frost motif;
- one warm-side plant and one cold-side/dormant plant to communicate the distinction between growth stopping, death, and dormancy;
- title occupies the largest readable area;
- avoid dense tables or small numeric text in the preview.

## Style

- readable at thumbnail size;
- restrained RimWorld-compatible illustrated/game-mod presentation rather than photorealism;
- winter/cold visual language should be obvious, but the image should not imply that every crop simply dies in winter;
- dormancy should read as survival/sleep rather than death;
- no use of RimWorld copyrighted UI screenshots is required for the base preview.

## Text hierarchy

1. `Crop Cold Tolerance Overhaul`
2. `0.1 Beta`
3. `Growth temperature ≠ Cold death`

Do not place the full crop balance table in the preview. The Workshop description carries the numerical comparison.

## Release acceptance check

Before publication verify:

- `About/Preview.png` is present;
- exact dimensions are 640×360 or another approved 16:9 size;
- file size is below 1 MB;
- title remains readable at small mod-list thumbnail size;
- no text is clipped;
- normal RimWorld mod-list preview displays without blur/letterboxing.
